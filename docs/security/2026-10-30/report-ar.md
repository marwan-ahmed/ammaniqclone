## الحكم التنفيذي وحدود الاستنتاج

**المخاطر الكلية حرجة. الكود الحالي لا يوفر حماية خادمية لبيانات النظام وعملياته المالية؛ أوصي بعدم إتاحته لشبكة غير موثوقة قبل إغلاق النتائج الحرجة.** وجود شاشة Firebase وتأكيدات الحذف وإخفاء الأرقام لا يعالج غياب التحقق داخل API.

ثبت من المصدر وجود 17 مسار API تضم 26 معالج HTTP، كلها دون تحقق خادمي من الهوية أو صلاحية العملية أو السجل. تشمل النتائج إمكانية قراءة البيانات المالية والشخصية، تعديل الأدوار والإعدادات، وتنفيذ مسار مسح كامل. **وصول مهاجم من الإنترنت مشروط بإتاحة النشر؛ لم تُفحص حماية Vercel الخارجية ولم ينفذ أي طلب على الإنتاج.**

النطاق: ملفات التطبيق والإعدادات والمخطط وmigration والاختبارات وملف قفل 626 اعتماداً، وفحص توقيعات أسرار محدود في 132 ملفاً متتبعاً وتاريخ 60 commit. تمت مراجعة التوثيق وAPI والمنطق المالي والخصوصية بالتوازي ثم تدقيق الأدلة. لا يتضمن التقرير ادعاء اكتشاف جميع الثغرات الممكنة أو إثبات وقوع اختراق.

المنهج: مراجعة المصدر، تتبع تدفق البيانات، تشغيل الاختبارات والتحليل الساكن، `npm audit`، ومطابقة نشرات الموردين. لم تُقرأ قيم `.env.local`، ولم يُنفذ seed/reset/migration أو اختبار حمل أو payload على قاعدة بيانات أو خدمة حية. لم تُعدل شيفرة التطبيق أو اعتمادياته. أُضيف التقرير وملحقه ونتائج npm فقط، وحُدث ملف حالة العمل.

تمييز الأدلة: «مؤكد من المصدر» يثبت مساراً معيباً في الكود؛ «مؤكد محلياً» يضيف تجربة دون قاعدة بيانات؛ «مشروط» يحتاج إعداداً أو إجراء عمل محدداً؛ «فجوة ضمان» ليست استغلالاً مثبتاً. الشدة تقدير أثر وأولوية لهذا المشروع، وليست درجة CVSS محسوبة.

[deposits:17](D:/ajeeb-company/ahmed-eyad/app/src/app/api/deposits/route.ts:17) و[withdrawals:17](D:/ajeeb-company/ahmed-eyad/app/src/app/api/withdrawals/route.ts:17) لا يرفضان النص غير الرقمي لأن المقارنة مع NaN لا تتحقق.

- القبول: رفض النصوص غير الرقمية وNaN وInfinity والسالب والكسور/الأشهر خارج الحدود حسب سياسة المال قبل أي استعلام؛ الأرصدة لا تتغير عند الرفض.
